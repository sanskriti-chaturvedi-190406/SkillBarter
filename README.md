# SkillBarter

SkillBarter is a web application project designed to help people exchange skills and learn from one another. The project is currently in its initial setup stage.

## Tech Stack

- Frontend: HTML, CSS, JavaScript, Vite
- Authentication: Clerk
- Backend and database: Convex
- Package manager: npm

## Prerequisites

Install the following before running the project:

- Node.js (a current supported version)
- npm
- Git

You will also need access to a Clerk application and a Convex project.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/sanskriti-chaturvedi-190406/SkillBarter.git
cd SkillBarter
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment variables

Create a local environment file by copying the example:

```bash
Copy-Item .env.example .env.local
```

Add the appropriate values to `.env.local`:

```dotenv
VITE_CLERK_PUBLISHABLE_KEY=
VITE_CONVEX_URL=
VITE_CONVEX_SITE_URL=
```

Use the publishable key from your Clerk dashboard and the URLs generated by your Convex development deployment. Never commit `.env.local` or any secret keys.

### 4. Configure Convex

If you have access to the shared Convex project, follow the team's instructions for connecting to its development deployment. Otherwise, configure your own Convex development deployment:

```bash
npx convex dev
```

Follow the CLI prompts. Convex will configure the local deployment and generate the required client configuration.

For Clerk authentication, the Convex deployment also needs the `CLERK_JWT_ISSUER_DOMAIN` environment variable configured with the correct Clerk issuer domain. See the team setup instructions before changing shared deployment settings.

### 5. Start the frontend

In one terminal:

```bash
npm run dev
```

Open the local URL printed by Vite.

Keep the Convex development process running in another terminal when working on backend functions.

## Available Scripts

| Command | Purpose |
| --- | --- |
| `npm run dev` | Start the Vite development server |
| `npm run build` | Build the frontend for production |
| `npm run preview` | Preview the production build |
| `npx convex dev` | Start Convex development and sync backend functions |

## Project Status

The repository currently contains the Vite frontend starter and the initial Clerk and Convex setup. The complete application features and workflows are still under development.

Do not assume that authentication, skill listings, matching, messaging, or other product features are implemented until they have been added and tested.

## Team Workflow

- Use `main` as the shared integration branch.
- Work on separate feature branches.
- Keep commits focused and descriptive.
- Test changes before opening a pull request.
- Merge into `main` after review.
- Never commit `.env.local`, secret keys, or other credentials.

## Security Notes

- `.env.local` contains machine-specific configuration and must remain untracked.
- `.env.example` contains variable names and placeholders only.
- The Clerk publishable key is intended for frontend use; Clerk secret keys must never be exposed in frontend code.
- Coordinate changes to shared Convex deployments and authentication settings with the team.
